# Ұрпақтар таразысы — құқықтық тренажер

## GitHub Pages-ке орналастыру
1. ZIP архивін толық ашыңыз.
2. Репозиторийде Add file → Upload files таңдаңыз.
3. index.html, assets папкасы және қалған файлдарды бірге жүктеңіз. ZIP файлдың өзін жүктемеңіз.
4. Commit changes басыңыз.
5. Settings → Pages → Deploy from a branch → main → /(root) → Save.
6. Жариялау аяқталғанда Pages бөлімінде көрсетілген сайт сілтемесін ашыңыз.

index.html репозиторийдің түбінде, assets оның қасында болуы керек.
Бейнелердің сапасы өзгертілген жоқ; бастапқы файлдағы бейнелер жеке MP4 ретінде сақталды.
Бейнелер мен пайыздар — шартты оқу моделі, нақты ғылыми болжам емес.
