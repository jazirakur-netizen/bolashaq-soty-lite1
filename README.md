# BOLASHAQ SOTY Lite

9-сынып оқушысына арналған экологиялық-құқықтық оқу тренажері.

## Мүмкіндіктері

- 3 экологиялық кейс;
- 7 критерий бойынша 0–10 балдық бағалау;
- Болашақ ұрпақ құқығына қауіп индексін есептеу;
- 25, 50 және 100 жылдық шартты болжам;
- Оқушының жеке сот шешімі мен дәлелдері;
- Формуласы мен шешім шкаласы көрсетілген әдістемелік бөлім.

## Компьютерде іске қосу

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud-қа орналастыру

1. Осы папкадағы `app.py` және `requirements.txt` файлдарын GitHub репозиторийіне жүктеңіз.
2. Streamlit Community Cloud-та жаңа қолданба ашыңыз.
3. Негізгі файл ретінде `app.py` таңдаңыз.
4. Deploy батырмасын басыңыз.
5. Дайын сілтемені Notion парақшасындағы «BOLASHAQ SOTY тренажері» бөліміне қойыңыз.

## Авторлықты қорғауда түсіндіру

Оқушы кейстерді, 7 критерийді, бастапқы балдарды, индекс формуласын және шешім шкаласын түсіндіреді. Кодты рәсімдеу кезінде AI техникалық көмекші ретінде қолданылғаны ашық көрсетіледі.
